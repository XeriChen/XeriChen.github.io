## 1. 启动与准备

Antigravity CLI（命令为 `agy`）是 Google Antigravity 平台提供的终端命令行界面。

在已安装环境的终端中，运行以下命令即可启动：

```bash
# 启动进入交互模式
agy

# 启动并直接提交任务
agy "检查当前代码库中的测试用例"
```

首次运行时，按照屏幕提示登录账号完成授权即可。

---

## 2. 核心使用方式与斜杠命令

在 `agy` 交互界面中，除了直接输入文字与 Agent 沟通外，主要通过斜杠命令控制任务执行方式。

输入 `/help` 可以列出所有可用的命令，常用命令说明如下：

| 命令 | 主要功能 | 适用场景 |
| :--- | :--- | :--- |
| `/plan` | 生成逐步执行计划 | 涉及多个文件修改或重构等复杂任务时 |
| `/goal` | 开启目标导向模式 | 需要自动持续执行直至完成的耗时任务 |
| `/schedule` | 设置定时器或定期提醒 | 监控后台任务状态或设置提醒通知 |
| `/learn` | 持久化保存操作习惯 | 希望 Agent 记住特定的编码风格或项目约束 |
| `/grill-me` | 开启对话式提问 | 需求尚不明确、需要通过问答理清思路时 |
| `/clear` | 清理当前对话记录 | 开启新任务、避免历史上下文干扰时 |

## 3. 常用快捷键与终端操作

在 CLI 界面交互过程中，可以使用以下快捷键控制输入与响应：

| 快捷键 | 功能说明 |
| :--- | :--- |
| **`Ctrl + C`** | 中断当前 Agent 的输出或正在运行的命令 |
| **`Ctrl + D`**（连按两次） | 退出 `agy` 终端界面 |
| **`Tab`** | 自动补全斜杠命令或文件名路径 |
| **`Shift + Enter`** 或 **`Alt + Enter`** | 在输入框中换行（进行多行文本输入） |
| **`Ctrl + L`** | 清屏并保持当前对话状态 |

## 4. 配置文件与参数设置

Antigravity CLI 的配置文件保存在本地固定路径：

```text
~/.gemini/antigravity-cli/settings.json
```

可以通过编辑该 JSON 文件调整默认配置。常用配置项如下：

```json
{
  "model": "auto",
  "autoAccept": false,
  "theme": "system",
  "contextWindow": 8000
}
```

字段功能说明：

* **`model`**：指定默认使用的模型类型（如 `auto` 自动选择或指定模型名称）。
* **`autoAccept`**：设置是否自动接受并运行 Agent 建议的终端命令。出于安全考虑，默认建议设为 `false`（手动确认）。
* **`theme`**：控制 CLI 界面配色主题，可选 `dark`、`light` 或跟随系统 `system`。
* **`contextWindow`**：单次会话保留的最大上下文长度限制。

另外，如果需要在项目级别设置统一的行为规范，可以在仓库根目录下创建 `AGENTS.md` 文件，CLI 会自动读取并执行文件中的要求。
